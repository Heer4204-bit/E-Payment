DIGITAL LOGIC GATES & SEMICONDUCTOR THEORY
AND Gate

Outputs 1 ONLY when all input signals are turned ON (High current flow).

OR Gate

Outputs 1 if AT LEAST ONE input signal is ON.

XOR Gate

Outputs 1 if AT LEAST ONE input signal is ON.

XOR Gate

Outputs 1 if inputs are DIFFERENT. Fundamental for binary arithmetic adders.

NOT Gate

Inverts the incoming signal state (0 to 1, or 1 to 0).
